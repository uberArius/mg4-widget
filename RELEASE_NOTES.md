# v0.7.0 — visible alarm causes and direct tile selection

## ENG

- Alarm-causing tiles now turn red, and the app names the causes above the dashboard.
- Tyre pressures display two decimal places: 2.38 bar no longer looks like 2.4 while triggering the < 2.4 alarm.
- Tap dashboard tiles to select/deselect them for the widget. A ✓ and position number show selection. Newly selected tiles go to the top.
- Hold and drag selected tiles to change their order. Changes save immediately; the separate selection list has been replaced by the dashboard.

Warnings use the last stored readings, which may be old. Android 12+. Polish main UI. Debug-signed test build. **Expiry unchanged: 25 November 2026, 00:00 UTC.** Remote vehicle-data reliability and climate confirmation still require field testing. No application source published; third-party licenses remain embedded and included in the documentation archive.

## PL

- Czerwone są również kafelki powodujące alarm; aplikacja wymienia przyczyny nad panelem.
- Ciśnienie z dwoma miejscami po przecinku: 2,38 bar nie wygląda już jak 2,4 przy aktywnym alarmie < 2,4.
- Dotknięcie kafelka w panelu wybiera/usuwa go z widżetu. ✓ i numer oznaczają wybór. Nowo zaznaczony trafia na początek.
- Przytrzymanie i przeciągnięcie wybranego kafelka zmienia kolejność. Zapis jest natychmiastowy; panel zastępuje osobną listę wyboru.

Ostrzeżenia korzystają z ostatnich odczytów, które mogą być stare. Android 12+. Główny interfejs po polsku. Testowy podpis debug. **Termin bez zmian: 25 listopada 2026, 01:00 w Polsce (00:00 UTC).** Odczyty z auta i potwierdzanie klimatyzacji wymagają dalszych prób.
